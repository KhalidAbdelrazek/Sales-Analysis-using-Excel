# 📊 Sales Analytics Dashboard (Excel)

A fully interactive **Sales Analytics Dashboard** built entirely in **Microsoft Excel** to analyze 60,000+ transactions and extract actionable business insights. This project demonstrates the power of Excel as a **Business Intelligence (BI) tool** for handling large-scale data.

## 💡 Key Insights from the Dashboard

* **Explosive Growth**: Revenue grew from **$30M (2005)** to **$108M (2008)**—a 37× increase in transactions.
* **The Profit Paradox**: Cheap products represent **75% of volume** but only **5% of profit**, while high-end items drive **95% of the bottom line**.
* **The "Silver" Economy**: Customers aged **50+** contribute nearly **40% of total profit**.
* **Operational Timing**: **71.8% of total profit** is generated during weekdays.
* **Geographic Focus**: The **USA and Australia** together generate **60% of total profit**.

---

## 🛠️ Tools & Techniques Used

* **Data Modeling**: Power Pivot for managing 60,400+ rows.
* **Dynamic UI**: Slicers, Timeline filters, and Interactive KPIs.
* **Advanced Analytics**: Pivot Tables and Pareto analysis (80/20 rule).
